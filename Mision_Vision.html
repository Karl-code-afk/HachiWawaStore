Nuestra Infraestructura

Servidores

HachiWawa está alojado utilizando GitHub Pages, una plataforma de hosting estático rápida, segura y confiable que nos permite mantener la tienda disponible 24/7 de forma global.

Equipo de Desarrollo

El código de nuestra tienda es escrito y mantenido utilizando equipos de cómputo portátiles (Laptops) optimizados para desarrollo web, asegurando movilidad y eficiencia en la implementación de nuevas características.

Tecnologías y Plataformas Digitales

Para construir esta plataforma, utilizamos:

  • Estructura y Diseño: HTML5 nativo y CSS3 puro.
  • Interactividad: JavaScript (Vanilla JS) para el carrito y localStorage.
  • Tipografía: Google Fonts (Quicksand y Fraunces).
  • Entorno de Desarrollo: Visual Studio Code y GitHub Codespaces.
  • Control de Versiones: Git y GitHub.
